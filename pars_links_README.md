# Цены ПРОКОНСИМ из страниц

Положите `pars_links.py` и `link.csv` в одну папку. В `link.csv` укажите
полные ссылки на страницы магазина: одна ссылка в строке. Заголовок `link`
необязателен. Кодировка UTF-8. Дубли ссылок обрабатываются один раз.

```csv
link
https://proconsim.ru/адрес-страницы/
https://proconsim.ru/другая-страница/
```

Установка и запуск в PowerShell из этой папки:

```powershell
python -m pip install playwright
python pars_links.py
```

1. Скрипт открывает Chrome (если его нет — Edge) с отдельным профилем магазина.
2. Выберите регион, дождитесь загрузки сайта и нажмите Enter в терминале.
   Проверку сайта, если появится, пройдите самостоятельно.
3. Скрипт сохраняет куки и поочередно открывает ссылки в том же окне браузера.
4. Собирает пары из загруженного HTML, включая изменения JavaScript,
   и прокручивает страницы для загрузки карточек.
5. Записывает результат в `all-price.csv` рядом со скриптом.

Для артикула из текста `Арт:&nbsp;143100025` берётся первый элемент с классом
`price-current` после артикула и до следующего артикула. Пробелы, переносы строк,
неразрывные пробелы и вложенные теги внутри цены поддерживаются.
Строки без распознаваемой цены пропускаются. Старые цены не используются.

Результат — две колонки: `Артикул;Цена`. Цена `8 372,34 ₽` записывается как
`8372,34`, начальные нули артикула сохраняются в CSV. При импорте в Excel
выберите текстовый тип колонки артикула, чтобы Excel сам не убрал нули.
Кодировка результата UTF-8 с BOM.

Одинаковые пары удаляются, разные цены одного артикула сохраняются обе,
с предупреждением в терминале. После каждой страницы результат сохраняется.
При ошибке страницы скрипт продолжает работу, в конце перечисляет неудачные
ссылки и возвращает код завершения 1. Нулевое количество найденных пар
также считается ошибкой страницы.

По умолчанию после загрузки есть пауза 2 секунды и до 60 прокруток.
На медленном сайте или длинной странице их можно увеличить:

```powershell
python pars_links.py --wait 5 --scroll-rounds 150
```

Отключить прокрутку: `--scroll-rounds 0`. Пагинация и кнопки «Показать ещё»
не нажимаются: внесите все нужные страницы в `link.csv`.

Если Chrome/Edge отсутствуют:

```powershell
python -m playwright install chromium
python pars_links.py --browser chromium
```

Куки, состояние сайта и отдельный профиль хранятся в `.proconsim-links`
рядом со скриптом. Не публикуйте эту папку. При каждом запуске скрипт
снова просит проверить регион. Обычный профиль вашего браузера не используется.

Проверено только на локальных примерах HTML и с имитацией браузера.
Реальный сайт для проверки не открывался.
